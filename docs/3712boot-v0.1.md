# 3712BOOT v0.1 hardware test

`3712BOOT.COM` is intentionally a **load/verify-only** step toward direct CP/M 2.2 booting from the Altair FDC+ firmware 1.8 Drive Type 8 interface.

It does **not** jump into the loaded CP/M image and contains no write or format commands.

## What it loads

The supplied `CPM22v1.0-FDC+3712-48K.dsk` boot sector identifies the 48K layout used by the disk image:

- CCP base: `A600h`
- BIOS base: `BC00h`
- loaded system range: `A600h-BF7Fh`

Mike Douglas's original cold loader uses physical interleave 2 on the two system tracks:

- track 0: physical sectors `3,5,...25,2,4,...26` (25 sectors; sector 1 is the boot loader)
- track 1: physical sectors `1,3,...25,2,4,...26` (26 sectors)

`3712BOOT.COM` reproduces that sequence using the same direct FDC+3712 read commands already proven by `3712TEST.COM`.

## Verification

After loading all 51 sectors, v0.1 verifies:

1. the first 16 bytes of the CCP at `A600h`;
2. the first 16 bytes of the BIOS jump table at `BC00h`;
3. the additive 16-bit checksum of `A600h-BF7Fh`.

The expected checksum for the supplied 48K image is `54B0h`.

If all checks pass, the program reports success and returns to the currently running CP/M. It deliberately does not transfer control to `BC00h` yet, because the loaded BIOS still contains calls to the original FDC+3712 PROM vectors at `F400h` and its console configuration has not yet been adapted for the IMSAI target system.
